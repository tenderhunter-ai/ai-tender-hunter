# AI Tender Hunter — صيّاد المناقصات الذكي

منصة SaaS عربية لاكتشاف وتحليل فرص المناقصات والتوريدات في مصر.

## المزايا
- صفحة رئيسية تسويقية + صفحة باقات.
- تسجيل الشركات وملف تعريفي (نشاط، منتجات، محافظات عمل).
- محرك بحث للمناقصات (كلمة/قطاع/محافظة/مصدر) مع تصنيف حسب نشاط الشركة.
- درجة ملاءمة (0–100) لكل مناقصة مقابل ملف الشركة مع أسباب التقييم.
- تحليل كراسات الشروط PDF: ملخص، مواعيد، بنود مالية (كراسة/تأمين ابتدائي/نهائي/غرامات)، مستندات مطلوبة، شروط قد تمنع التقديم، جدول كميات، قائمة مراجعة، مسودة خطاب تقديم وهيكل عرض فني.
- تنبيهات المواعيد النهائية داخل المنصة.
- نظام اشتراكات وباقات (دفع تجريبي فقط — لا خصم حقيقي).
- لوحة إدارة: مستخدمون، اشتراكات، مراجعة وإضافة مناقصات، مصادر بيانات، نظام استيراد بديل، تقارير استخدام وإيرادات.
- 20 مناقصة مبدئية: 10 موثقة من مصادر عامة (بلقطة بتاريخ 2026-11-28 ورابط المصدر) و10 تجريبية موسومة صراحة.
- 3 حسابات شركات تجريبية + حساب إدارة.
- كراسة شروط تجريبية PDF (`sample-booklet.pdf`) لتجربة التحليل.

## التشغيل
```bash
npm install
npm start        # يبذر قاعدة البيانات تلقائياً عند أول تشغيل
```
متغيرات البيئة: `PORT`، `APP_SECRET` (إلزامي في الإنتاج)، `ADMIN_EMAIL`، `ADMIN_PASSWORD` (يُنشآن ويُطبعان في السجل عند أول بذر إن لم تُمررا)، `DB_PATH`.

## التقنية
Node.js 22 (SQLite مدمجة `node:sqlite` — بلا قاعدة خارجية)، Express، pdf-parse، محرك تحليل عربي بالقواعد اللغوية v1 (مصمم لتوصيل نموذج لغوي لاحقاً خلف نفس الواجهة).

## الصدق التشغيلي
- لا بيانات مختلقة: المناقصات الموثقة موسومة بمصدرها وتاريخ اللقطة، والتجريبية موسومة «تجريبية».
- لا تجاوز لأي حماية أو تسجيل دخول في المواقع الحكومية؛ بوابة etenders.gov.eg القديمة متعذرة الوصول وموثقة في لوحة الإدارة، ويعوّضها نظام الاستيراد اليدوي.
- الدفع تجريبي فقط لحين اعتماد بوابة دفع.
- النتائج الآلية مساعدة وقابلة للخطأ ولا تغني عن مراجعة الكراسة الأصلية، ولا ضمان للفوز بأي مناقصة.
- المسودات لا تُقدَّم رسمياً إلا باعتماد صاحب الشركة.
